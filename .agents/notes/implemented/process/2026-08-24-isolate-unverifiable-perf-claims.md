# Agent Note: 隔离不可审计的历史性能结论

Status: implemented

## Problem

仓内存在早期写下的性能结论，其原始环境、构建参数、原始结果已不可考。
留在正文里会被读者当作当前可复现的事实引用——性能声明没有绑定
代码 + 环境 + 原始结果 + 适用边界，就不是证据而是噪音。

## Decision

不可审计的历史性能结论从现行文档面**隔离**（commit `685a6c4`，
2026-08-24）：现行性能叙事只保留能在当前仓库内复现的部分；历史数字
或删除、或移入明确标注为不可审计的历史记录。后续性能结论必须绑定
代码版本、硬件环境、原始结果与适用边界才可写入文档。

## Alternatives considered

- **原地保留并加「历史」字样** — 改动最小；但正文里混着不可复现数字，
  读者仍会引用，免责声明挡不住摘抄。
- **全部删除** — 最干净；但丧失了「曾经有过这条叙事」的记录价值，
  隔离保留了可追溯性。

## Consequences

- **收益**：仓内可见的性能数字 = 可复现的数字；与组织级「证据绑定」
  原则一致。
- **代价**：丢了部分叙事厚度；新性能结论的写入门槛变高（必须带
  原始结果包）。

## Verification

CHANGELOG 与 docs 中的性能表述均可定位到仓内 benchmark/结果文件；
`685a6c4` 提交 diff 可见隔离范围。
